# Recap video

Drop the vertical recap here as `recap.mp4` (optionally `recap-poster.jpg`
for the still frame shown before playback).

The player frames a 9:16 video for wide screens by standing it upright in
the centre at full height, with a blurred, scaled copy of the same footage
filling the space either side. On phones it simply fills the width. Until
the file exists the section shows a short "coming soon" card instead.
