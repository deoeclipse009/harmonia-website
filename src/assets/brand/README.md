# Brand seal

Drop the official profile-picture artwork here as `seal.png` (or .jpg/.webp)
and the site will use it everywhere in place of the built-in SVG recreation.

It renders inside a circular container clipped to the red disc, the piano
legs that extend past the disc are cropped automatically. If the crop sits
wrong for your export, tune `--seal-zoom` / `--seal-y` in
src/components/SealLogo.css.
